# 手机局域网访问

Hard 默认只使用 `127.0.0.1`，不会向局域网或公网开放。

若要让同一 Wi-Fi 下的手机访问：

1. 在“设置与数据 → 手机访问”中选择检测到的 RFC1918 私有 IPv4 地址。
2. 阅读并勾选“同一网络设备可访问数据并运行代码”的风险确认。
3. 启用后使用显示的本地 URL 或二维码打开页面。

该设置只生成经过验证的私有网络启动配置；它不创建端口转发、公共隧道或 Windows 防火墙规则。页面中的 PowerShell 命令仅供人工预览，绝不会自动执行。每次应用重新启动后都回到 loopback，必须再次明确确认。

不要在公共 Wi-Fi、酒店、校园开放网络或任何不受信任的网络中启用。Hard 没有登录或配对机制；同一网络上的设备可以查看学习数据并提交代码。

断线期间，阅读位置、知识题答案、笔记和代码草稿保存在当前浏览器。恢复连接时，只会用原有幂等键提交尚未确认的请求；已成功项目不会重复提交。
