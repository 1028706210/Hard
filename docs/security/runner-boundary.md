# Runner 安全边界

本文说明 Hard 代码运行器的信任模型、实际具备的防护与明确的非目标。结论先说：**运行器只适合运行你自己编写的学习代码（TRUSTED_LOCAL_LEARNING_ONLY），不能安全运行恶意代码。**

## 信任模型

- Hard 是单用户本机应用：没有认证、没有隔离的多租户，API 只绑定 `127.0.0.1`（LAN 模式需在设置页显式开启并确认风险）。
- 运行器把用户提交的源代码在本机真实编译并执行。这不是沙箱、容器或虚拟机：被运行代码拥有当前用户的大部分权限，可以访问该用户能访问的文件与网络。

## 实际具备的防护

以下为运行器实现的运行边界（目的：防止意外事故拖垮学习会话，而非抵御恶意代码）：

| 防护 | 行为 |
| --- | --- |
| 编译限时 | 15 秒超时，超时标记 `compile_timeout` 并回收进程。 |
| 运行限时 | 5 秒超时，超时标记 `run_timeout` 并回收进程。 |
| 输出上限 | 64 KiB；超出即终止进程，标记 `output_limit_exceeded`，防止输出刷爆内存与页面。 |
| 进程树回收 | 结束、超时、溢出或取消时按进程树终止（`terminate_process_tree`），不遗留编译器/运行时子进程。 |
| 隔离工作区 | 每次运行使用 `runner-work\` 下的独立临时目录，运行后清理；全部位于 D 盘项目目录内。 |
| 取消 | 运行中的任务可取消，取消路径同样回收进程树与临时目录。 |
| 仅本机暴露 | 运行 API 仅经本机回环访问；LAN 模式默认关闭且重启后复位。 |

## 非目标（明确不具备）

- 不防御恶意代码：无系统调用过滤、无文件系统/网络隔离、无资源硬配额（CPU、内存、磁盘）。
- 不支持多用户隔离：任何能访问 Web 端口的人都能提交并运行代码。
- 不做防病毒或内容审查。

## 使用建议

- 只粘贴与运行你理解的学习代码；从网上复制代码前先通读。
- 不要在运行器中输入或泄露密码、密钥等敏感信息。
- 若需要运行来源不明或故意恶意的代码，请使用真正的隔离环境（虚拟机、容器、一次性系统）。
- 手机访问开启后，同一网络的任何设备都能提交代码运行；仅在可信的私有网络中短暂开启。
