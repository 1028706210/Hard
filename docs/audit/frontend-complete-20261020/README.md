## 实际修改与原因

- 首页保留深色知识星图，使用已有星云美术和四语言图标，重排主题内曲线、当前概念的跨语言关联与真实学习状态；连线不伪称先修关系，缺失映射不伪装成可学习节点。流光、星尘、呼吸及图标漂浮均保留暂停和减少动态支持。

- 导航保留当前课时上下文，手机菜单支持 Escape 关闭并还原焦点；手机课时目录提高层级，关闭按钮不再被顶部导航遮住。
- 课程目录与正文重排阅读层级，正文目录取自实际标题；练习工作区保留真实编辑器、运行、评分、草稿和反馈，桌面并排、手机编辑器/结果切换。
- 每题分别保存反馈；修正旧答题请求迟到覆盖新答案、新错误，以及废弃课时加载重置当前选题的竞态。真实失败请求仍进入离线队列。
- 对照页按每页 4 个概念展示，全部 45 个概念可到达；筛选与页码写入已有路由查询参数，进入课时后返回可恢复上下文。
- 搜索区分正在编辑与已提交的查询，复习区分计划队列与普通薄弱线索；成长页筛选、分页展开和设置页分区改善长页面阅读。
- 76 篇不同课文的深化与事实修正、共享概念整合另见 [内容汇总](../content-depth-20261021/README.md)。当前 45 概念、111 available、69 missing。

改动复用 Vue、Vue Router、已有图像与组件，没有新增产品依赖。未改写任何 AGENTS.md，没有提交、推送、打标签、部署或开启局域网访问；所有既有未提交成果保留。
