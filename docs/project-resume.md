# Hard 项目技术栈与简历说明

状态日期：2026-10-21。以下数据来自项目源码和本机验收记录，不包含线上用户、并发压测或商业运营数据。

## 项目定位与当前进度

Hard 是面向个人学习的本地优先编程学习平台，覆盖 Python、Java、C#、C++ 四条学习路线，连接课程阅读、代码编写、真实编译运行、评分、复习和成长记录。默认仅监听本机回环地址，支持 Windows 本地启动与响应式界面。

当前已完成核心功能闭环并通过本机试运行验收。内容库包含 282 个课时、282 份练习，45 个跨语言概念及 111 个可用语言映射；69 个缺失映射保留明确标记。课时数按独立课程条目统计，不等于每个知识点都已经完整讲授。最新一轮深化和事实修正覆盖 76 篇不同课文。

## 可用于简历的项目介绍

**Hard｜本地优先的多语言编程学习平台**

技术栈：Vue 3、TypeScript、Vite、Monaco Editor、FastAPI、SQLAlchemy、SQLite / FTS5、Alembic、pytest、Vitest、Playwright。

- 设计并实现课程阅读、在线编辑、四语言本地运行与自动评分、错题复习、全文检索和成长分析的学习闭环，使用 Markdown / YAML 管理 282 个课时与配套练习。
- 实现 Python、Java、C#、C++ 统一运行任务模型，支持异步状态查询、取消、编译/运行超时、输出限制和进程清理；通过幂等请求避免重复提交产生重复业务效果。
- 构建真实课程数据驱动的交互知识星链与跨语言对照，组织 45 个公共概念、111 个可用语言映射，支持概念筛选、课时跳转、动效暂停和移动端访问。
- 实现本地编辑草稿与离线补交队列，修复迟到响应覆盖最新答题结果、页面返回丢失筛选等状态一致性问题；提供备份导出、校验与恢复流程。
- 建立分层自动化验证：后端 269 项测试、前端 117 项测试、真实浏览器 53 项用例通过；后端覆盖率 96.31%、前端行覆盖率 92.15%，四组核心模块覆盖率均达到 95% 门禁。

以上职责句应根据本人真实参与范围选用，不必全部放入简历。建议保留 3～4 条与目标岗位最相关的内容；如主要承担产品策划、技术统筹或 AI 辅助开发，应如实调整角色称谓。

## 面试时需要讲清的技术边界

- 这是本地运行平台，没有经过生产高并发、海量用户或分布式系统验证。运行任务使用本机线程池与子进程管理，没有采用消息中间件或容器集群。
- Runner 适用于可信个人学习代码；资源限制和进程清理不构成可安全执行恶意代码的隔离沙箱。
- 复习使用基于评分的间隔调度，不应写成机器学习推荐系统。知识星链是课程/概念关系可视化，不是图数据库或大模型知识图谱。
- 当前内容仍在逐章深化，不应写成四语言教学内容全部完成；没有真实用户量、吞吐量、性能提升百分比时不填写这些指标。
- 当前验证使用本机 Node 24.8.0，项目固定 Node 24.17.0 / pnpm 11.19.0 的正式发布环境尚未重新认证；Monaco 编辑器分块体积仍有优化空间。
