# Hard 使用指南

本指南只描述实际可用的功能：启动与停止、学习流程、代码运行、手机访问、数据位置与恢复、安全边界。

## 启动与停止

最方便的方式：双击项目根目录的 **启动 Hard.cmd**，启动成功后自动打开网页；结束使用时双击 **停止 Hard.cmd**。如自行创建桌面快捷方式，应指向这两个入口；项目文件夹移动或改名后需要重新设置快捷方式。关闭浏览器不会停止服务，已经运行时可以直接重新打开 `http://127.0.0.1:4173`。

启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start-hard.ps1
```

- 默认端口：API `8000`、Web `4173`，均为仅本机回环；可用 `-ApiPort` / `-WebPort` 更换。
- 首次启动自动准备数据库；需要升级时先备份，失败时恢复。已有最新数据库不会重复迁移，数据库和工具链就绪后才提示启动成功。
- 若上次实例未停止，会提示“已在运行”，先运行停止脚本再启动。
- 若端口被其他程序占用，会明确指出端口并拒绝启动；请释放端口或换端口，不要结束不明进程。
- 启动失败时会回收本次已拉起的进程，并在 `.tool-cache\hard-start\api.log`、`web.log` 留下日志。

停止：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop-hard.ps1
```

只停止本次启动记录的 API 与 Web 进程树，并等待端口释放；没有运行实例时提示“未发现正在运行的实例”。

## 学习流程

主页的知识星图包含 Python、Java、C#、C++ 四组星座，每组按“基础语法”“函数与组织”“数据与对象”组织。首页显示每组的代表性知识点，全部45个概念均可在下方搜索切换；切换后相应星点会进入所属分组。计数显示该语言已映射数/主题总概念数。主题内连线用于探索，不表示先修依赖。点击知识点会联动下方“跨语言共鸣”，查看相同处、各语言的不同处、示例与对应课时；也可以搜索和切换其他概念。暂无对应课时的星点置灰，不绘制跨语言连接。

点击语言名称或图标，在主页展开该语言的模块星链，再选择模块和课时；“打开课程目录”可进入完整目录。“继续学习”仍使用真实学习进度。右侧“暂停星空动效”可暂停星尘漂移、图标浮动、星点呼吸、扩散光环与连线流光，系统开启“减少动态效果”时自动关闭这些动画。

1. 打开 `http://127.0.0.1:4173`，从主页选择路线（Python / Java / C# / C++）并进入“继续学习”。
2. 每节课先阅读目标与示例，再完成知识题；代码题在编辑器中点击运行，得分即时显示。
3. 错题自动进入复习队列；复习评级会影响到期时间与掌握度。
4. “搜索”可全文查找课程内容；“对照”页可按概念查看四种语言的写法与对应课时链接。
5. “成长报告”显示可读课程名称、掌握度、经验、等级、徽章和最近90天的学习热力图。每个日期格的说明显示真实已完成练习数和记录时间；没有记录的日期保持空色，访问记录不会被算成完成练习。挑战与分级测试通过后会提升路线状态。

## 代码运行

代码题与挑战在你的浏览器提交后由本机运行器执行：编译限时 15 秒、运行限时 5 秒、输出截断于 64 KiB；运行中可取消，进程树与临时工作区会被回收。运行器只适合运行你自己编写的学习代码，不能安全运行恶意代码（见 `docs/security/runner-boundary.md`）。

## 手机访问（可选 LAN 模式）

默认仅本机。要让同一 Wi-Fi 下的手机访问：

1. 在“设置与数据 → 手机访问”中选择检测到的 RFC1918 私有 IPv4 地址。
2. 勾选“同一网络设备可访问数据并运行代码”的风险确认。
3. 使用页面显示的 URL 或二维码打开。

注意：Hard 没有登录或配对机制，启用后同一网络的设备可以查看学习数据并提交代码；不要在公共 Wi-Fi 或不受信任的网络启用。每次重启后自动回到仅本机，需要再次确认。断线期间阅读位置、答案、笔记与代码草稿保存在浏览器，恢复后以幂等键补交，不会重复提交。

## 数据位置与备份恢复

- 数据库：`data\`；自动备份：`backups\`；手动导出：`exports\`；运行工作区：`runner-work\`。全部位于 D 盘项目目录内。
- 在“设置与数据”中创建导出包（zip）；导入时只选择你自己保存的归档，导入会覆盖当前学习数据。
- 同一 D 盘的备份不能防止硬盘损坏，重要节点请把导出包复制到其他介质。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示“已在运行” | 先运行 `scripts\stop-hard.ps1`。若提示记录不兼容或进程身份不符，保留记录并核查原实例，不要按其中的 PID 手动结束其他程序。 |
| 提示端口被占用 | 释放端口或用 `-ApiPort` / `-WebPort` 换端口；不要终止不明进程。 |
| 启动失败 | 查看 `.tool-cache\hard-start\api.log` / `web.log`；失败路径会自动回收已启动进程。 |
| 运行代码报超时/输出截断 | 属预期限制（5 秒 / 64 KiB），请精简程序输出或降低计算量。 |
