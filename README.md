# Hard

Private source snapshot of the Hard programming-learning project.

## Contents

- `apps/web/`: web application source.
- `apps/api/`: API source and Python dependency definitions.
- `content/` and `packages/`: learning content and shared packages.
- `tests/`, `scripts/`, `tools/`: checks and project tooling.
- `docs/`, `项目md/`, and `TASKS.md`: project documents and recorded task state.

Start with [Windows toolchain setup](docs/setup/windows-d-drive.md),
[Python guide](docs/setup/python-user-guide.md), and `package.json`.
The locked JavaScript dependency versions are in `pnpm-lock.yaml`.
`.env.example` contains the local configuration template.

This repository preserves current working files. The original local Git
worktree was not repaired, and its commit history is not included in this
snapshot. Dependency folders, build output, local databases, user data,
credentials, and logs are excluded.

Uploading this snapshot does not start or accept any development task.
